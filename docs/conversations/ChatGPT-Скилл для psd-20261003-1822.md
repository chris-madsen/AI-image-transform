## Рабочий код создания Raster Mask

```javascript
function cTID(value) {
    return charIDToTypeID(value);
}

function addRasterMaskFromSelection() {
    var descriptor = new ActionDescriptor();
    var reference = new ActionReference();

    descriptor.putClass(
        cTID("Nw  "),
        cTID("Chnl")
    );

    reference.putEnumerated(
        cTID("Chnl"),
        cTID("Chnl"),
        cTID("Msk ")
    );

    descriptor.putReference(
        cTID("At  "),
        reference
    );

    descriptor.putEnumerated(
        cTID("Usng"),
        cTID("UsrM"),
        cTID("RvlS")
    );

    executeAction(
        cTID("Mk  "),
        descriptor,
        DialogModes.NO
    );
}
```

`RvlS` означает Reveal Selection. Если нужна пустая белая маска, используется `RvlA` - Reveal All.

## Как перенести нашу AI-маску в Raster Mask

Лучше всего передавать `mask.png` так:

- RGB = белый;
- alpha = рассчитанная маска `0…255`.

В Python:

```python
mask_rgba = np.empty((height, width, 4), dtype=np.uint8)
mask_rgba[..., :3] = 255
mask_rgba[..., 3] = mask_uint8
```

Затем в Photopea:

```javascript
function loadActiveLayerTransparencyAsSelection() {
    var descriptor = new ActionDescriptor();

    var selectionReference = new ActionReference();
    selectionReference.putProperty(
        cTID("Chnl"),
        cTID("fsel")
    );
    descriptor.putReference(
        cTID("null"),
        selectionReference
    );

    var transparencyReference = new ActionReference();
    transparencyReference.putEnumerated(
        cTID("Chnl"),
        cTID("Chnl"),
        cTID("Trsp")
    );
    descriptor.putReference(
        cTID("T   "),
        transparencyReference
    );

    executeAction(
        cTID("setd"),
        descriptor,
        DialogModes.NO
    );
}
```

Полная последовательность:

```javascript
var doc = app.activeDocument;
```

## Проверка существования Raster Mask

Не стоит полагаться только на чтение свойства `UsrM` через `executeActionGet`: в Photopea такие запросы поддерживаются не полностью.

Надёжнее попытаться выбрать канал маски:

```javascript
function selectRasterMaskChannel() {
    var descriptor = new ActionDescriptor();
    var reference = new ActionReference();

    reference.putEnumerated(
        cTID("Chnl"),
        cTID("Chnl"),
        cTID("Msk ")
    );

    descriptor.putReference(
        cTID("null"),
        reference
    );

    descriptor.putBoolean(
        cTID("MkVs"),
        false
    );

    executeAction(
        cTID("slct"),
        descriptor,
        DialogModes.NO
    );
}
```

Если Raster Mask отсутствует, операция завершится ошибкой. Поэтому правильная проверка:

1. Выбрать `WORKING ART`.
2. Выполнить `selectRasterMaskChannel()`.
3. Экспортировать PSD через `saveToOE("psd:true")`.
4. Снова открыть полученный PSD через ArrayBuffer.
5. Найти `WORKING ART`.
6. Повторно выбрать его Raster Mask.
7. Только после этого ставить `psd_validation_status = passed`.
